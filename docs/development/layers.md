# 开发环境分层设计

本文说明个人开发容器中各类数据的归属、生命周期和更新方式。设计目标是让镜像可以重复构建，让用户状态可以长期保留，同时不需要提前知道每一种工具会把登录态写到哪里。

## 镜像层

镜像层负责提供可重复构建的开发能力，包括：

1. 系统包和命令行工具。
2. Git、Agent 等需要随镜像分发的公共配置。
3. 用户目录首次初始化时所需的默认内容。

镜像层不能包含登录凭证、访问令牌或其他与具体用户和开发机绑定的数据。镜像重新构建后可以替换旧镜像，但不应直接覆盖已经存在的用户层。

## 用户层

用户层是项目目录下的 `data/home`，它会绑定挂载到容器内的 `/home/dev`。这里保存工具运行过程中产生的所有用户状态，例如：

- Codex 的登录缓存。
- GitHub CLI 和阿里云 CLI 的登录状态。
- Docker 客户端配置。
- npm、pip 和其他包管理器的私有仓库配置。
- 未来新增工具写入用户目录的状态。

选择持久化整个 Home，而不是逐项挂载工具目录，是为了给未知工具提供统一的兜底机制。即使以后新增的工具使用了新的配置路径，也不需要修改开发容器的挂载清单。

`data` 目录必须同时被 Git 和 Docker 构建上下文忽略，防止凭证被提交到仓库或复制进镜像。

## 用户层初始化

绑定挂载不会像新的 Docker 数据卷一样，自动复制镜像中已有的目录内容。因此，`start.sh` 会在正式创建开发容器前完成首次初始化：

1. 构建本地开发容器镜像。
2. 检查 `data/home` 是否为空。
3. 从镜像创建一个不运行的临时容器。
4. 使用 `docker cp` 将临时容器中的 `/home/dev` 复制到 `data/home`。
5. 删除临时容器。
6. 将初始化后的目录绑定挂载到正式开发容器的 `/home/dev`。

复制时不使用 `docker cp -a`。这样复制到宿主机的文件属于执行 `start.sh` 的宿主机用户，而不是保留镜像构建时使用的 UID 和 GID。

初始化只在 `data/home` 为空时执行。镜像后续重新构建不会覆盖用户已经修改的配置和登录状态。如果确实需要从头初始化，应先备份需要保留的数据，再清空 `data/home`。

## 工作区层

宿主机的 `~/workspace` 会绑定挂载到容器内的 `/home/dev/workspace`。源码始终保存在宿主机，而不是镜像或用户层中，因此可以同时从宿主机和容器访问。

开发容器创建时会通过 `updateRemoteUserUID` 让容器内 `dev` 用户的 UID 和 GID 与宿主机用户一致，避免双方编辑工作区时产生文件权限冲突。具体机制见[用户机制说明](user.md)。

## 宿主机集成层

需要直接复用宿主机能力的资源通过独立的绑定挂载提供：

- 宿主机的 `~/.ssh` 挂载到容器的 `/home/dev/.ssh`。
- 宿主机的 Docker socket 挂载到容器的 `/var/run/docker.sock`。
- 宿主机的 `/etc/localtime` 以只读方式挂载到容器中的相同位置。

这些资源不复制到用户层。尤其是 SSH 密钥，只应引用宿主机上的原始文件，不应进入镜像、项目数据目录或 Git 仓库。

## 密钥层

Infisical 是可集中管理密钥的来源，适合保存 Access Token、API Key 等非交互式凭证。工具支持环境变量认证时，应在执行具体命令时按需注入密钥，避免把所有密钥长期导出到 Shell 环境。

不同凭证按以下规则处理：

1. 浏览器、设备码等交互式登录在容器内执行一次，登录状态由用户层持久化。
2. 支持环境变量的 Access Token 由 Infisical 按进程注入。
3. 工具必须生成本地凭证文件时，该文件留在用户层。
4. Git 和 Docker 等工具的 Credential Helper 可以作为后续增强，但不作为通用凭证机制，因为不同客户端使用的接口并不统一。

## 生命周期边界

各层的生命周期如下：

| 分层 | 数据位置 | 更新方式 | 删除容器后 |
| --- | --- | --- | --- |
| 镜像层 | Docker 镜像 | 重新构建 | 保留镜像内容 |
| 用户层 | `data/home` | 工具运行和用户操作 | 保留 |
| 工作区层 | 宿主机 `~/workspace` | 日常开发 | 保留 |
| 宿主机集成层 | 宿主机原始路径 | 由宿主机管理 | 不受影响 |
| 密钥层 | Infisical 或用户层登录缓存 | 登录、刷新或轮换 | 保留 |

概括来说：镜像定义工具和初始环境，用户层保存不可预测的个人状态，工作区保存源码，宿主机集成层提供本机能力，Infisical 管理适合动态注入的秘密。
